# Welcome to TradLive 🎙️

Real-time AI translation platform for conferences, events, and professional meetings.

## 🌍 What We Do

TradLive provides **simultaneous AI-powered translation** with ultra-low latency (1 second). We support:
- 🎤 **Conference Mode** — Live transcription & translation for up to 10,000 participants
- 👥 **Translator Mode** — Bidirectional real-time translation
- 🔒 **Zero-Log Architecture** — Complete privacy & GDPR compliance

## 📊 Our Stack

| Component | Technology | Repository |
|-----------|-----------|-----------|
| **Frontend** | Next.js 16 + React 19 + Tailwind | [TradLive_Vercel](https://github.com/TradLive/TradLive_Vercel) |
| **Conference Backend** | Python + vLLM + Ably | [TradLive_Conference_Runpod](https://github.com/TradLive/TradLive_Conference_Runpod) |
| **Translator Backend** | Python + Deepgram + Ably | [TradLive_Translator_Runpod](https://github.com/TradLive/TradLive_Translator_Runpod) |

## 🤖 Open-Source Models

We use cutting-edge open-source AI models:
- **STT** — Kyutai STT-1B (CC-BY 4.0)
- **Translation** — Google MADLAD-400-3B (Apache 2.0)
- **TTS** — Rhasspy Piper (GPL-3.0)
